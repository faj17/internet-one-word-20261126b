One word for the whole internet: **unhinged**. No filter, no restraint, no
supervision — the internet in a single word, funny by itself and true of the
whole thing rather than one app or one mood.

## How it works

`main.py` assembles the word from fragments, validates it against the
competition gate (one word, 1–30 characters, not only white space), and
writes it to `/output/entry.txt` with no trailing newline.

```sh
python3 main.py
```
